LISTING PREVIEW - GITHUB PAGES
==============================
Upload everything in this folder (index.html, the media folder and .nojekyll)
to the top level of a new public GitHub repository, then turn on Pages:
Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
The live link appears on that Pages screen after a minute or two.

The page is marked "noindex" so search engines won't list it while it's a preview.
Remove the <meta name="robots" ...> line in index.html when it goes public for buyers.
